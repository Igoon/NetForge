# NET FORGE v0.36.1 — GitHub Pages PWA

Unggah isi folder ini ke root repository GitHub Pages. Akses melalui https://igoon.github.io/NetForge/ .

Gunakan tombol **Cek Update** pada kiri bawah untuk melihat versi terbaru dan apa saja yang berubah. Dialog update akan menampilkan daftar perubahan dari `version.json`.

Backend tetap kompatibel dengan v0.35.2. Jangan unggah token API, file .env, atau database ke repository publik.
