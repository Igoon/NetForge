# v0.40.67 — session + logout integration

Logout now attempts to revoke the *current* Sanctum access token as well as the refresh token when the provided bearer token belongs to the same user as the refresh session. The API remains POST /api/v1/auth/logout.

IMPORTANT: other existing access tokens remain active until expiry. A true revoke-all-devices endpoint would require authentication, explicit confirmation, and additional policy checks; not implemented.

This is source code for an existing Laravel app; it requires Sanctum, Google Client, migrations, CORS, public HTTPS deployment and testing. Static PHP lint is not integration testing.
